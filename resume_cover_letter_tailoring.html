Resume & Cover Letter Tailoring

Companion tool — takes a real job posting and your actual resume, and tailors both to it honestly.

Where this fits. Not sure what to target yet? Career Path Discovery helps you figure that out first. Once you know your direction: the Target Company Prompt Builder finds companies, the Job Posting Finder finds real openings, the Outreach Message Builder drafts your first message. This tool picks up once you've decided to actually apply — it doesn't invent anything new about you, it re-emphasizes and re-orders what's already true in your resume, and drafts a cover letter grounded in the same facts.
1 · The job posting

Full text works better than a summary — the more of the actual posting language you paste, the better the keyword/gap analysis. Tailoring more than 2-3 postings at once tends to dilute the depth of each — this works best focused on your highest-priority opportunities, not your whole tracker at once.

"Yes" (default) asks Claude to search "[Company] recruiter" and similar, then — if more than a couple of names turn up — figure out which one is actually best suited to this specific posting based on their title and LinkedIn info (e.g. a "Technical Recruiter — Cybersecurity" is a better match for this role than a "Recruiter — Finance & Accounting" at the same company). When found with reasonable confidence, the name is used to personalize the cover letter/match letter salutation instead of "Dear Hiring Manager." If that function-based search comes up empty, a second, broader search runs automatically — by the posting's location and by role-appropriate seniority — before falling back to a generic salutation. Any candidates found this second way are listed for you to choose from rather than picked automatically, since they're a lower-confidence match than a direct department fit. Requires the Web search capability — see the settings note below.

3 · What to generate

Independent checkboxes — check any combination you want this run. Cover Letter Draft and Qualifications Match Letter (T-Letter) can both be checked at once if you want both formats for the same posting. The two "apply" checkboxes are optional add-ons — they don't replace the recommendation tables, they ask for a ready-to-use updated resume on top of them. Each can be checked independently, or both together for one resume reflecting both categories of changes. Each is explained in the User Guide.

Not required — if you leave this blank, Claude infers the gap between your resume's apparent trajectory and this posting on its own. Fill it in if you want to steer that framing yourself. This only asks Claude to reorder/re-emphasize what's already true and to flag genuine skill/certification gaps worth naming — same non-invention rule as everything else on this page. If you're not sure yet which direction to pursue at all, the Career Path Discovery tool (Step 0) is the better starting point.

Applies to both Cover Letter Draft and the Qualifications Match Letter's opening and closing paragraphs, if either is checked.

1 page is the conventional standard for most roles. 2–3 pages fits certain executive-level, federal, or narrative-heavy applications where a longer, more detailed letter is expected — don't default to this unless the posting or role level actually calls for it. The Qualifications Match Letter (T-Letter) is always kept to 1 page regardless of this setting, since its whole purpose is a fast, scannable read.

4 · Output
This is the one non-negotiable rule in the generated prompt: nothing gets invented. Every resume bullet suggestion is a re-emphasis or re-wording of something already in your pasted resume — never a new employer, title, metric, achievement, or credential that wasn't there. The cover letter draws only on your resume and the additional context you provided. If your resume genuinely doesn't have something the posting wants, the gap analysis says so plainly instead of a bullet quietly inventing it.
